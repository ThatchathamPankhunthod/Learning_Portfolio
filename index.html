What I Built

ผมสร้างเว็บไซต์เพื่อแนะนำตัวและนำเสนอผลงานการเรียนรู้ โดยใช้ HTML กำหนดโครงสร้าง และ CSS ตกแต่งหน้าเว็บ

  • ส่วนแนะนำตัวและข้อมูลการศึกษา

How I Built It

ขั้นตอนการทำงาน

  1. วางแผน

    ศึกษาตัวอย่างเว็บไซต์และกำหนดโครงสร้างหน้าเว็บ

  2. เขียน HTML

    จัดเนื้อหาเป็นส่วนต่าง ๆ เช่น header, main และ footer

  3. ตกแต่งด้วย CSS

    กำหนดสี ระยะห่าง และขนาดตัวอักษร

  4. พัฒนาด้วย Bootstrap

    ใช้ Grid เพื่อจัดวางเนื้อหาให้เหมาะกับหน้าจอ

  5. เผยแพร่เว็บไซต์

    จัดเก็บโค้ดด้วย GitHub

เครื่องมือที่ใช้: HTML · CSS · Bootstrap · Git · GitHub

Reflection

ปัญหาและความท้าทาย

หลังจากที่ผมได้ทำ A1 แล้วนั้นได้พบว่าสามารถเข้าใจ CSS มากขึ้นแต่เมื่อได้ใช้ Bootstrap ได้พบว่าสามารถใช้งานได้ง่ายยิ่งขึ้นแต่พบปัญหาตรงที่ว่าตัวของการ์ดใช้ Class เยอะเกินไปอาจทำให้สับสนได้

สิ่งที่ได้เรียนรู้

ได้เรียนรู้ในการใช้ Grid ในการจัดหน้าเว็บ และมีการใช้งาน Bootstrap ร่วมด้วย รวมถึงการจัดโครงสร้างหน้าเว็บและการใช้ Git สามารถพัฒนาเว็บไซต์ให้รองรับหลาย Device

สิ่งที่อยากพัฒนาต่อ

อยากพัฒนาเว็บไซต์ให้มีการเก็บฐานข้อมูล มีการตอบโต้กับ User และมีการใช้งาน Backend
